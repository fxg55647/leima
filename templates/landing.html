How it works

Turn a source and a question into a result you can understand, share and verify.

01
Add a source
Upload a document, paste text, add a URL, email, image or GitHub repository.
02
Ask a question
Tell Leima what you need to establish, compare or check in the source.
03
Get a sealed report
See what the source supports, what it does not, and when the analysis was made.

What can you use it for?

Start with the source you already have. Leima is useful anywhere the exact contents and timing of a record matter.

Contracts
Find what an agreement actually promises and where it is unclear.
Emails
Clarify what was agreed and what a message said at the time.
Invoices & receipts
Compare a receipt, order, delivery record or other documents.
Web pages
Record what a page showed when it mattered.
Images & scans
Analyse photographed or scanned evidence and preserve its fingerprint.
GitHub
Understand what a repository or code change actually does.
What Leima does — and does not — prove: Leima shows what a source contains and what the analysis supports. It does not decide who is legally right, or guarantee that the original source was truthful.
Analyse a source

The original document is processed and then discarded. Only the cryptographic fingerprint, verdict and timestamp are sealed. Validate a record.
